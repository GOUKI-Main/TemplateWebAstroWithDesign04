# フォントのライセンス

このサイトは次の4書体を Astro Fonts API（`astro.config.mjs` の `fonts`）で
ビルド時に取得し、サイト内から配信しています。いずれも
[SIL Open Font License 1.1](https://openfontlicense.org/) で、商用サイトでの
利用・配信が認められています（フォント単体の販売は不可）。

| 書体                    | 用途             | 著作権者                         | 入手元                                                    |
| ----------------------- | ---------------- | -------------------------------- | --------------------------------------------------------- |
| Zen Kaku Gothic Antique | 本文             | Yoshimichi Ohira                 | https://fonts.google.com/specimen/Zen+Kaku+Gothic+Antique |
| Kaisei Decol            | 大見出し         | Font-Kai                         | https://fonts.google.com/specimen/Kaisei+Decol            |
| Yomogi                  | 手書き風の見出し | Satsuyako                        | https://fonts.google.com/specimen/Yomogi                  |
| Josefin Sans            | 欧文の添え字     | The Josefin Sans Project Authors | https://fonts.google.com/specimen/Josefin+Sans            |

ライセンス全文: https://openfontlicense.org/open-font-license-official-text/
